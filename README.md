# TaskMate

App per la gestione delle attività in casa e della spesa. Condividi case, compiti e liste con la famiglia.

## Tecnologie

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase (backend)

## Avvio in locale

Requisito: Node.js e npm ([nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
npm i
npm run dev
```

Apri [http://localhost:8080](http://localhost:8080).

## Script

- `npm run dev` – server di sviluppo
- `npm run build` – build per produzione
- `npm run preview` – anteprima della build
- `npm run lint` – ESLint
- `npm test` – test (Vitest)
